# Project Reports

This folder contains the visual outputs and summary materials for the Olist business analytics project.

## Included dashboard exports
- overview-dashboard.svg
- revenue-by-state.svg
- monthly-trend.svg

## Notes
These assets correspond to the executive dashboard and supporting visuals used to communicate:
- total revenue and average order value
- strongest customer states by revenue
- monthly demand and revenue patterns
- portfolio and seller concentration insights

The source data and detailed SQL logic are stored in the project data and SQL folders.
